A compact chess engine in 4 KB of Python: 0x88 board, alpha-beta search with a transposition table and quiescence search, piece-square evaluation, and a fixed 100,000-node budget per move. It plays the make.fun tiny-chess-01 gauntlet through the env at MAKEFUN_ENV_URL. The engine source is packed with lzma to fit the 4,096-byte limit.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8471 python3 main.py
```
